# GeamNews

**GeamNews** es la plataforma editorial de **GeamEnergy** para comunicar novedades corporativas, avances tecnológicos, iniciativas estratégicas y contenidos relevantes del sector energético.

Diseñada como un sitio estático, GeamNews prioriza rendimiento, claridad de lectura y acceso rápido a la información.

## Sitio oficial

La plataforma está disponible en:

**https://flaviofonck.github.io/geamnews/**

## Objetivo del proyecto

GeamNews tiene como propósito centralizar la comunicación institucional de GeamEnergy mediante:

- Publicación de noticias y actualizaciones corporativas.
- Difusión de hitos de innovación, proyectos y alianzas.
- Visibilidad de iniciativas vinculadas a sostenibilidad y energía.
- Consolidación de un canal digital confiable para audiencias internas y externas.

## Lineamientos de contenido

Para mantener un estándar profesional en la comunicación de GeamEnergy, se recomienda que cada publicación incluya:

- Título claro y orientado al negocio.
- Fecha de publicación visible.
- Estructura breve con contexto, desarrollo y conclusión.
- Enlaces o referencias cuando corresponda.
- Consistencia de tono institucional y terminología de marca.
